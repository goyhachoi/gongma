# gongma — 공감마케터 SNS 이미지 호스팅 (실사용)

> 🔴 **강사 실사용 저장소예요.**
> 여기 이미지는 **이미 Buffer에 예약·발행된 것들**이라, 덮어쓰면 **발행된 글의 그림이 사후에 바뀝니다.**
> 수강생 테스트는 이 저장소가 아니라 **`goyhachoi/member`**를 쓰세요.

《AI 10인 마케팅팀》 직원 4호(SNS 작가)가 만든 카드뉴스·썸네일을 올려 두는 곳이에요.
Buffer가 **발행 시점에** 여기서 이미지를 가져갑니다.

## 왜 GitHub인가요

Buffer는 이미지를 자기 서버에 복사해 두지 않고, 예약한 글이 **발행되는 순간**에 URL로 가지러 와요.

- 🚫 Replicate 주소(`replicate.delivery`)는 **약 1시간 뒤 만료** → 발행이 조용히 실패
- ✅ GitHub raw 주소는 만료가 없음

## 폴더 구조

```
sns/
└── {image_slug}/          ← 콘텐츠 1건 = 폴더 1개
    ├── ig-01.png … ig-09.png    인스타 카드뉴스 (1080×1350)
    └── fb-01.png                페북 썸네일 (1536×1024)

(루트)  캐릭터 시트·레퍼런스 이미지 — gonggam-* / sheet_* / reference-*
```

`image_slug`는 원고 프론트매터의 **콘텐츠 단위 고유값**이에요. 주차로 묶지 않아요 —
묶으면 같은 주 두 번째 글이 첫 번째 이미지를 덮어써요.

## 올리는 법

직접 올리지 않아요. `Marketing_hub/04_sns/publish-images.ps1`이 해줘요.

```powershell
powershell -ExecutionPolicy Bypass -File "{HUB}\04_sns\publish-images.ps1" "{원고 파일명}"
```

## 🔴 되돌릴 수 없는 것

- **이미 예약된 글의 이미지를 바꾸지 마세요.** 스크립트가 기본으로 덮어쓰기를 막아요.
  정말 바꿔야 하면 `-Force`인데, 그 전에 Buffer 예약을 먼저 취소하세요.
- **저장소를 Private으로 바꾸지 마세요.** 예약된 글이 전부 조용히 실패해요.
